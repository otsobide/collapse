What it does

Everything you need to squeeze a file. Nothing you don't.

Files & folders

Compress a single file or a whole directory tree; the structure survives the round-trip.

7z · ZIP · tar

Standard archives any other tool can open, with five levels to trade speed for size.

Compress & extract

It goes both ways: drop an archive back in and the format is detected for you.

Two modes

Compress on this machine, or hand the work to a Collapse server you run yourself when you would rather a stronger one did it. Pick per archive; local is the default.

App & command line

One engine behind a calm window and a terminal command, so clicking and scripting produce the same archive.

Safe extraction

An archive can never write outside the folder you picked, however it was crafted.
